# 价值评分准入门禁

版本：`ashare_value_evaluation_v1` / 1.0

当前结论：**Scoring readiness: BLOCKED**

## 边界

本文件只定义未来若要进入评分阶段必须先满足的可审查条件，不设计分值、权重、数值阈值、等级或买卖规则。事实、指标、评价、评分和投资结论是五个不同层次；当前可信的六项指标只提供描述性证据。

## 十二项准入门禁

| 门禁 | 当前状态 | 阻塞证据 |
|---|---|---|
| 每个评分维度有明确理论来源 | blocked | 维度框架已建立，但尚未逐维形成可证伪的操作定义 |
| 每个分数可追溯至 Metric Result ID | blocked | 尚无评分模型，也不应提前建立映射 |
| 缺失不等于零 | blocked | 缺口清单仍包含盈利质量、资本回报、安全、分红和估值事实 |
| 周期企业有单独解释规则 | blocked | 仅有原则，尚无跨周期样本与行业基准 |
| 至少有多年趋势 | partial | 六项指标有 2021—2025 趋势，但其他评价维度缺失 |
| 必要时有行业或历史基准 | blocked | 尚无可信同行样本和长期估值历史 |
| 阈值有经验或统计依据 | blocked | 尚未做样本研究；不得凭经验硬编码 |
| 权重经过敏感性分析 | blocked | 权重尚未提出，且在事实覆盖前不应提出 |
| 风险否决项不被其他高分抵消 | blocked | 否决项事实与治理证据合同尚未建立 |
| 事实、指标、评分版本化 | partial | Fact Schema 2.1 和 Metric Schema 1.0 已版本化，评分层不存在 |
| 不把评分写成买卖建议 | policy_ready | 北极星已明确禁止，但仍需未来实现测试 |
| 人工评审通过 | blocked | 评分合同不存在，无法评审 |

只有十二项均有证据通过，才可另立阶段讨论评分；任何 partial 或 blocked 都保持 `NOT YET`。通过门禁也只允许建立可解释的研究辅助，不自动允许生成交易建议。

## 复核方式

- 每项通过必须绑定版本化文档、测试或结果 ID，不接受口头宣称。
- 多年趋势必须使用 Point-in-Time 可得版本，并保留重列链。
- 行业比较必须先统一会计口径、期间、单位和合并范围。
- 缺失、不可比或分母失真必须显式呈现，不得以零代替。
- 风险否决项与其他维度分开表达，不能靠汇总抵消。
- 未来若研究阈值或权重，应新开受控阶段，记录样本、方法、敏感性与人工批准。

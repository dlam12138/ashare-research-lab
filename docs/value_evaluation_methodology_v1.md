# A 股价值评价方法论基线 v1

方法论 ID：`ashare_value_evaluation_v1`

版本：1.0

状态：方法论基线；描述性证据可信；评分尚未准入

## 1. 方法论目标

本方法论为个人本地研究工具建立一套可追溯、可复算、可反驳的价值研究语言。它把官方披露事实转换为透明指标，再由人结合行业、周期、会计口径和风险证据形成评价。它不把缺失当成零，不用单一比率替代研究，也不输出买卖建议。

当前事实层有 75 个冻结的 Fact ID，指标层有 38 个冻结的 Metric Result ID；Fact Schema 2.1 和 Metric Schema 1.0 已足够承载本阶段。本阶段不改 Schema、不新增事实、不计算新指标。

## 2. 好企业、好价格与好投资

- **好企业**是经营与资本配置问题：盈利来源、现金实现、资本回报、资产负债表韧性、治理和价值兑现是否经得起多年与周期检验。
- **好价格**是预期与估值问题：市场价格隐含的增长、回报和风险假设，相对可审慎估计的价值是否留有余地。
- **好投资**还包含投资者自身的时间跨度、机会成本、组合风险、流动性和行为纪律。

三者不能互相替代。企业质量高不意味着任意价格都合适；价格低不证明企业优质；二者同时成立也不自动产生适合任何人的交易结论。李大霄增补稿在本项目中只用于长期主义、风险纪律和行为约束，不提供公式、权重或时点信号。

## 3. 五层边界

```text
官方披露事实 → 透明指标 → 有条件的研究评价 → 未准入的评分 → 人的投资结论
```

**事实 ≠ 指标；指标 ≠ 评价；评价 ≠ 评分；评分 ≠ 买卖建议。**

事实必须带来源、期间、可得日、版本和血缘。指标必须有显式公式、输入 Fact ID、计算版本和 PIT 语义。评价必须说明上下文、反例和未知项。评分只有在门禁全部通过后才可另行研究。任何层级都不能越级产生交易建议。

## 4. 盈利质量

盈利质量研究关注利润是否来自可重复的主营经营、是否与收入和现金流相互印证、是否受一次性项目、会计估计或合并范围变化显著影响。归母净利润同比只是变化证据，不是质量结论。

下一步需要扣非归母净利润、营业成本、营业利润和非经常性损益。毛利润应由同口径收入与营业成本透明构造。分析必须同时阅读附注、审计意见、会计政策变化和重列，不得把利润增长直接解释为竞争优势。

## 5. 现金流质量

IAS 7 和中国现金流量表准则将现金流按经营、投资、筹资活动分类；非现金交易需要另行理解。经营现金流与利润的长期关系可提示营运资本、非现金项目或利润实现问题，但二者口径并不完全相同，不能把比率 1 机械设为绝对好坏边界。

`cash_based_free_cash_flow_proxy` 是“经营现金流减购建长期资产现金支出”的狭义代理，不是完整 FCFF 或 FCFE。`cash_paid_for_fixed_assets_to_revenue` 只是已登记现金支出相对收入的量级，不能无条件称为完整资本开支强度。

## 6. 资本回报

资本回报回答“企业使用股东或全部投入资本创造了什么回报”，与利润增长不同。ROE、ROA 通常需要期间利润与平均资产负债表余额匹配；只使用期末余额会混合 duration 与 instant 口径。ROIC 还涉及经营利润、税、经营与融资项目划分、现金和租赁负债等判断。

在归母权益、总资产和可信期初/期末余额未覆盖前，不计算 ROE/ROA。ROIC 的 NOPAT 与投入资本口径存在方法选择，必须先登记定义、替代项和边界，不能为了得到数字而伪造精确性。

## 7. 财务安全

财务安全不是单一负债率。至少要观察总负债、短期借款、长期借款、应付债券、租赁负债、利息费用、货币资金及现金等价物，并结合到期结构、受限资金、表外承诺和现金流稳定性。

周期企业在高景气期可能显得安全、低景气期现金流却快速收缩。安全评价应以多期 PIT 数据和压力情景为背景；尚未覆盖这些事实时，只能登记缺口。

## 8. 经营稳定性

稳定性要求多年趋势，而非把低波动等同优秀。收入、利润和经营现金流应共同观察，并解释商品价格、销量、汇率、政策、资产处置、并购和口径变化。单一年份同比不得直接评分；低基数、负分母和重列都可能使百分比失真。

对中国石油这类周期企业，波动本身是商业模式事实。研究重点是完整周期中的盈利、现金和资产负债表韧性，而不是要求每年平滑增长。

## 9. 治理与风险否决项

审计非标准意见、重大会计差错、监管处罚、关联交易异常、资金占用、重大诉讼、持续经营疑虑和信息披露失信等风险应独立展示。未来即使存在综合评价，这类风险也不能被其他维度的较好表现自动抵消。

本阶段没有建立治理事实模型或否决逻辑，因此不作结论，只把它们保留为评分前的强制缺口。

## 10. 分红与价值兑现

现金分红和回购体现价值向股东兑现的一部分，但需要区分董事会方案、股东大会批准、实施日期和实际支付。回购还要区分注销、库存股或激励用途。分红率、股息率都需要匹配正确分母和 PIT 价格。

高分红不自动等于价值创造，低分红也可能对应高回报再投资。必须结合资本回报、融资需求、周期和资产负债表评价。

## 11. 估值与安全边际

估值是对未来现金流、增长、资本回报和风险假设的表达，不是把历史财务比率贴上便宜或昂贵标签。PE、PB、PS、股息率及历史分位均需 PIT 股价、股本/市值、可得日和一致的财务版本。

周期企业的峰值利润会压低 PE，谷底利润可能使 PE 失真；应采用跨周期盈利能力、资产质量和情景分析。当前没有可信价格历史与市场价值事实，故不计算估值或安全边际。

## 12. 周期企业特殊处理

中国石油同时受油气价格、产销量、炼化价差、汇率、税费、资本开支和政策影响。解释合同要求：

- 至少覆盖一个更完整的周期，不能用单年同比定性；
- 把价格与经营能力的变化分开讨论，无法拆分时明确未知；
- 关注高景气期资本纪律与低景气期流动性；
- 对利润、现金流、资产减值和资本支出采用情景而非固定阈值；
- 同行比较先统一业务结构、会计口径和国家政策环境。

## 13. Point-in-Time 与财报重列

PIT 查询只能使用研究时点已经公开的事实版本。Qlib 的 PIT 设计说明了财务数据后续修订若覆盖历史会造成泄漏；本项目因此保留 `available_at` 和版本链。后续年报比较列出现重列时，原始披露事实仍保留，新版本以 `supersedes` 关系连接。

所有六项现有指标都要求 PIT，也都可能受输入事实重列影响。评价必须指明“当时可知”还是“当前最新复核”视图，不能混合两个时间面。

## 14. 缺失数据处理

缺失、未核验、不可比、分母失真和不适用是不同状态，均不得写成零。当前明确缺少：扣非净利润、利润率所需事实、非经常性损益、ROE/ROA/ROIC 基础、财务安全、分红回购和估值。

Concept Registry 中已经存在某个 Concept，只表示语义入口已登记，不表示已有可信官方事实。缺失时保留问题和阻塞原因；不得用后续报告比较列、第三方口径或估算值静默填充。

## 15. 评分准入条件

当前结论是 **Scoring readiness: BLOCKED**。六项指标的 `score_eligible` 全为 `false`。评分前必须同时满足 [评分准入门禁](value_scoring_readiness_gates.md) 的十二项要求，包括理论来源、Result ID 追溯、多年与基准、缺失语义、周期规则、阈值证据、权重敏感性、风险否决、版本化和人工评审。

本版本不设计分值、权重、阈值、等级、总分或上涨概率。

## 现有六指标解释合同

### revenue_yoy

- **中文名称 / 精确公式 / 单位：** 营业收入同比；`(本年营业收入 / 上年营业收入) - 1`；ratio。
- **输入事实：** 同一主体、CAS、合并口径、相邻年度的 `revenue` duration facts。
- **理论用途：** 描述经营规模年度变化，并与利润和现金变化交叉核对。
- **能回答：** 本年收入相对上年方向和幅度；三类同比是否同向。
- **不能回答：** 可持续增长、市场份额、竞争优势，以及价格/销量/汇率/并购的贡献。
- **适用前提：** 期间与口径可比、上年分母有效；口径变更需重算对应版本。
- **周期与正负解释：** 正值仅表示增长，负值仅表示下降；对油气企业常受价格周期主导，均非独立好坏信号。
- **评分与比较：** 不可单独评分；需要多年趋势、行业/同行及业务量背景。
- **重列 / PIT / 信任：** restatement-sensitive；必须 PIT；当前为 TRUSTED descriptive evidence。
- **来源：** CFA 财务报表分析流程、财政部 CAS 28、Penman 的报表—经营—价值连接框架。

### net_profit_attributable_to_parent_yoy

- **中文名称 / 精确公式 / 单位：** 归母净利润同比；`(本年归母净利润 / 上年归母净利润) - 1`；ratio。
- **输入事实：** 相邻年度 `net_profit_attributable_to_parent` duration facts。
- **理论用途：** 描述归属于母公司股东的报告利润变化。
- **能回答：** 归母利润变化幅度；与收入和经营现金流是否背离。
- **不能回答：** 扣非后盈利、利润率、资本回报、估值或利润可持续性。
- **适用前提：** 分母有效、合并与归属口径一致，并检查一次性项目和会计政策。
- **周期与正负解释：** 正负值需结合基数、商品周期、减值和处置；由负转正等场景不宜用普通同比解释。
- **评分与比较：** 不可单独评分；需要多年、同行和扣非/非经常性证据。
- **重列 / PIT / 信任：** restatement-sensitive；必须 PIT；当前为 TRUSTED descriptive evidence。
- **来源：** CFA reporting quality、财政部 CAS 28、Penman。

### operating_cash_flow_yoy

- **中文名称 / 精确公式 / 单位：** 经营现金流同比；`(本年经营活动现金流量净额 / 上年经营活动现金流量净额) - 1`；ratio。
- **输入事实：** 相邻年度 `operating_cash_flow` duration facts。
- **理论用途：** 描述经营现金净流量变化，为利润实现与流动性研究提供线索。
- **能回答：** 经营现金净流入如何变化；是否与收入、利润同向。
- **不能回答：** 变化究竟来自营运资本还是核心经营；不能代替自由现金流和偿债分析。
- **适用前提：** 分类与期间可比，分母有效，并阅读现金流附注。
- **周期与正负解释：** 正值不必然改善、负值不必然恶化；库存、应收应付和税费时点可造成大幅摆动。
- **评分与比较：** 不可单独评分；需要多年、行业和营运资本背景。
- **重列 / PIT / 信任：** restatement-sensitive；必须 PIT；当前为 TRUSTED descriptive evidence。
- **来源：** IAS 7、CAS 31、CFA reporting quality。

### operating_cash_flow_to_attributable_net_profit

- **中文名称 / 精确公式 / 单位：** 经营现金流/归母净利润；`经营现金流 / 归母净利润`；ratio。
- **输入事实：** 同年度 `operating_cash_flow` 与 `net_profit_attributable_to_parent`。
- **理论用途：** 比较现金与归母利润量级，识别需要进一步解释的长期背离。
- **能回答：** 两者量级关系是否持续变化；是否需要检查营运资本和非现金项目。
- **不能回答：** 不能机械用 1 判定质量；不能消除分子与分母归属范围差异。
- **适用前提：** 分母不接近零，且理解折旧、减值、税费、利息、少数股东与营运资本影响。
- **周期与正负解释：** 负值和极端值首先提示分母状态或现金流方向；高值也可能来自营运资本释放而非经营改善。
- **评分与比较：** 不可单独评分；需多年趋势、行业与报表附注。
- **重列 / PIT / 信任：** restatement-sensitive；必须 PIT；当前为 TRUSTED descriptive evidence。
- **来源：** CFA reporting quality、IAS 7、Penman。

### cash_based_free_cash_flow_proxy

- **中文名称 / 精确公式 / 单位：** 现金基础自由现金流代理；`经营现金流 - 购建固定资产、无形资产和其他长期资产支付的现金`；万元。
- **输入事实：** 同年度 `operating_cash_flow`、`cash_paid_for_fixed_assets`。
- **理论用途：** 给出一个透明、狭义、可复算的现金余量代理。
- **能回答：** 该已登记长期资产现金支出后余量的方向和量级；多年投资阶段变化。
- **不能回答：** 不是完整 FCFF/FCFE；不包含所有资本性现金流，也不区分维持性和扩张性投资。
- **适用前提：** 两项现金流分类稳定且同口径；使用者接受代理范围。
- **周期与正负解释：** 正值仅表示狭义余量为正，负值可能是扩张投资或经营压力；需结合完整周期。
- **评分与比较：** 不可单独评分；需多年、行业资产强度及投资计划。
- **重列 / PIT / 信任：** restatement-sensitive；必须 PIT；当前为 TRUSTED cash-flow proxy。
- **来源：** IAS 7 的现金流分类、Damodaran 的现金流估值框架、McKinsey 的价值创造框架。

### cash_paid_for_fixed_assets_to_revenue

- **中文名称 / 精确公式 / 单位：** 长期资产现金支出/营业收入；`购建固定资产、无形资产和其他长期资产支付的现金 / 营业收入`；ratio。
- **输入事实：** 同年度 `cash_paid_for_fixed_assets`、`revenue`。
- **理论用途：** 描述已登记长期资产现金支出相对收入的量级。
- **能回答：** 相对收入的支出量级如何变化；是否处于不同投资阶段。
- **不能回答：** 不能无条件等同完整资本开支强度；不能判断投资回报或维持性支出。
- **适用前提：** 分母有效、现金支出分类稳定、收入与支出期间一致。
- **周期与正负解释：** 通常为非负，但较高或较低均需结合收入周期和建设时点；异常符号先查数据。
- **评分与比较：** 不可单独评分；需多年、行业资产强度和投资项目背景。
- **重列 / PIT / 信任：** restatement-sensitive；必须 PIT；当前为 TRUSTED descriptive evidence。
- **来源：** IAS 7、McKinsey、FinanceToolkit 的显式公式与指标分层理念。

### 开源架构：借鉴、适配与不照搬

| 项目 | 借鉴 | 适合原因 | 不照搬与本地裁剪 |
|---|---|---|---|
| [FinanceToolkit](https://github.com/JerBouma/FinanceToolkit) | 每项指标显式公式、单项与分类分层 | 支持复算和定义审查 | 不引入其数据源或大规模指标库，只登记六项已可信指标 |
| [OpenBB](https://docs.openbb.co/odp/python/developer/architecture_overview) | Provider 原始字段映射到标准模型并验证 | 与 SourceTier → Concept 的边界一致 | 不搭平台和插件市场，保留两个官方来源与本地模型 |
| [Qlib PIT](https://qlib.readthedocs.io/en/stable/advanced/PIT.html) | 按发布日期保留历史可得版本 | 防止用后见数据覆盖当时认知 | 不引入其存储或训练框架，沿用 `available_at` 和版本链 |
| [OpenLineage](https://github.com/OpenLineage/OpenLineage/blob/main/spec/OpenLineage.md) | Run、Job、输入/输出 Dataset 分离 | 结果可追溯到输入事实与运行 | 不接入外部服务，保留本地 Fact/Metric lineage |
| [Great Expectations](https://docs.greatexpectations.io/docs/core/define_expectations/) / [Pandera](https://pandera.readthedocs.io/en/stable/) | 把结构与业务约束变成可执行门禁 | 防止文档和注册表漂移 | 不新增运行时依赖；以 JSON、pytest 和现有模型实现最小门禁 |
| 北极星登记项目 | 研究问题组织、筛选与可视化启发 | 避免从零设计交互 | 不复制其信号、打分、数据许可或交易功能 |

本项目是单用户、本地、审计优先的研究工具，因此优先透明合同和小型文件，不扩张为通用数据平台。

# Agent Work Records

本目录用于保存项目开发和研究过程中的可追溯工作记录。

## 记录目的

当前主线可用能力统一见 [项目入口](../../README.md)。本目录仅记录历史操作和证据，不另维护当前阶段表。

每份记录应帮助后续人员回答：

- 当时为什么做这项修改？
- 实际查看了哪些文件？
- 执行了哪些操作？
- 为什么采用当前方案？
- 考虑过哪些替代方案？
- 使用了什么数据和参数？
- 做了哪些测试？
- 哪些内容没有完成？
- 当前结果是否可靠？
- 下一步从哪里继续？

## 文件命名

推荐格式：

```text
YYYY-MM-DD_HHMM_简短任务名.md
```

或者：

```text
YYYY-MM-DD_序号_简短任务名.md
```

任务名称使用小写英文和连字符，例如：

```text
2026-07-27_01_initialize-project-governance.md
2026-07-27_02_add-baostock-provider.md
2026-07-28_01_validate-petrochina-hypothesis.md
```

## 记录规则

- 一项任务对应一份主要记录；
- 执行过程中持续更新；
- 记录实际操作，不记录虚构步骤；
- 记录工程决策和研究依据；
- 不记录密码、Token、Cookie或私人敏感信息；
- 不粘贴冗长终端输出，只保留关键结果；
- 失败、警告和条件通过不得删除；
- 修改统计假设时必须保留修改痕迹；
- 最终记录应与实际Git差异一致。

## 建议状态

每份记录最终标记为以下状态之一：

- `completed`
- `partially_completed`
- `conditional_pass`
- `blocked`
- `failed`
